Privacy Policy

short version: there isn't much to track, and I don't.

What this site collects

Nothing, on my end. This is a static site — plain HTML, CSS, and JavaScript served from a file host. There's no server-side code, no database, no analytics script, and no ad network here.

Game progress (localStorage)

Some games save your progress — high scores, upgrades, streaks — directly in your browser using localStorage. That data:

  • never leaves your device or gets sent to me
  • is only readable by pages on this site
  • disappears if you clear your browser's site data

Hosting logs

Whoever hosts this site (a static host like GitHub Pages or Vercel) may keep standard server logs — IP address, browser type, timestamp — the same way almost any web host does. I don't have access to personally identify you from that, and I don't use it for anything.

Third-party links

Links off this site (like a donation link) go to other services with their own privacy policies. Once you click through, that's between you and them.

Changes

If this policy ever changes, this page will change with it. No notifications, no email lists — just check back if you're curious.
